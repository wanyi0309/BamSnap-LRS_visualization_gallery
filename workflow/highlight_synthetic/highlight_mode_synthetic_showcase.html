Synthetic Highlight Showcase

Eleven deterministic synthetic fixtures illustrating target-site allele assignment, phase-block handling, and alignment coloring in Highlight mode.

Scope. These fixtures test how Highlight mode applies a user-provided phased VCF to known synthetic alignment observations. They are deterministic software-behavior examples, not an independent phasing benchmark. Highlight mode does not independently phase samples, identify sequencing errors in real BAM data, or detect phase-switch errors. A single matching informative SNV can be sufficient for assignment, whereas discordant observations within a PS block can result in an unassigned (U) state.

How to read the plots

Coordinates. Plot regions and x-axis labels use 0-based, half-open coordinates ([start, end)); VCF POS values in the variant table are 1-based, as specified by VCF.

Observed allele. At highlighted SNV positions, the colored cell on an alignment reports the actual aligned A/C/G/T base. Deletions are shown as dark-gray target cells; reference skips and uncovered positions do not provide valid allele observations.

Haplotype state. Within each PS block, only phased, distinguishing SNVs are used for haplotype assignment. A unique match gives h1/h2; conflicting valid evidence gives U; no valid hap-informative observation gives ..

Clustering. Each displayed alignment record is classified independently. Alignments with identical complete block-wise signatures are clustered together; missing block states are not imputed.

Read-body color. A uniquely assigned PS span is filled with the VCF sample's phase color. h1 uses full opacity and h2 uses 50% opacity. In Highlight mode this PS color also has priority for supplementary alignment records.
